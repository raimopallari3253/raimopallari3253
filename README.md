# RAIMOPALLARI3253 — Performance Automotive

**Driven by Excellence.**

Professional responsive automotive storefront concept built with HTML, CSS and vanilla JavaScript.

## Brand identity
- Black `#101114`
- Sport Red `#E11D2E`
- Silver `#B8BEC7`
- Language: English
- Currency: USD

## Pages
- `index.html` — premium homepage
- `shop.html` — searchable, filterable demo catalog
- `about.html` — brand story
- `guides.html` — automotive inspiration
- `contact.html` — visual demo form (does not submit)
- `faq.html` — FAQ
- `shipping.html` — shipping and returns notice
- `privacy.html` — sample privacy policy
- `terms.html` — sample terms

## Files
- `assets/css/style.css` — responsive design
- `assets/js/products.js` — editable product data
- `assets/js/app.js` — catalog, cart and interaction logic

## Preview
Open `index.html` in a browser. An internet connection is needed for externally hosted Unsplash images and Google Fonts. Product photography is illustrative and may not depict the named item.

## GitHub Pages deployment
1. Create a new public repository, e.g. `raimopallari3253-auto`.
2. Upload all files and folders **at repository root**, including `index.html`.
3. Go to Settings → Pages → Deploy from a branch → `main` / `(root)`.
4. Visit `https://raimopallari3253.github.io/raimopallari3253-auto/` after deployment.

## Important limitations
This is a **demonstration only**. No real inventory, payments, checkout, shipping, customer service, or order processing exists. Prices are fictional examples. The cart uses browser localStorage. The contact form does not send messages. Legal pages are templates, not legal advice. Verify image usage and replace demo photos with properly licensed real product photography before commercial use.
